# Your Time Is Running Out — Premium Reel

A 15-second cinematic, motivational vertical Reel built with **Remotion + React + TypeScript**.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/santosarder477-maker/New-one/blob/main/render_video.ipynb)

| Spec | Value |
|---|---|
| Composition ID | `PremiumReel` |
| Resolution | 1080 × 1920 (9:16) |
| Frame rate | 30 fps |
| Duration | 15 s (450 frames) |
| Output | MP4, H.264 video + AAC audio |

## Edit structure

| Time | Scene | What happens |
|---|---|---|
| 0–3 s | `Hook` | "STOP / wasting / TIME" slams in with impact shake, flash, clock ring and ticking second hand |
| 3–7 s | `Kinetic` | Kinetic typography: "EVERY SECOND" (counter to 86,400) → "you scroll, you wait, you delay…" → "AND IT NEVER COMES BACK" |
| 7–12 s | `Progress` | Depleting time ring, 24 h countdown, "time gone" progress bars, accelerating ticks |
| 12–15 s | `Close` | "MAKE TODAY COUNT" with gold light sweep, rising embers, final underline |

Style: teal-and-amber colour grade, film grain, vignette, drifting light pools, a virtual camera (slow push-in, drift, impact shakes), directional motion blur on fast moves, and push-through zoom/blur transitions joined by light leaks.

## Assets and licences

- **Graphics:** all drawn in code (SVG/CSS). No stock images.
- **Fonts:** Bebas Neue, Playfair Display and Inter, all under the SIL Open Font License 1.1. They are bundled from npm (`@fontsource/*`), so rendering does not need a font server.
- **Soundtrack:** `public/soundtrack.wav` is generated by `scripts/generate-audio.mjs` from code (drone, ticks, whooshes, impacts). It uses no samples and no third-party audio. Run `npm run audio` to rebuild it.
- **Remotion licence:** Remotion is free for individuals and for companies with up to 3 employees. See https://www.remotion.dev/docs/license.

## Render in Google Colab (no local Node.js needed)

1. Open `render_video.ipynb` in Colab (use the badge above, or Colab → *File → Open notebook → GitHub* and paste this repository's URL).
2. Click **Runtime → Run all**.
3. Wait about 5–10 minutes. The MP4 then downloads automatically.

See the notebook's *Troubleshooting* section if something goes wrong.

## Local development (optional, needs Node 18+)

```bash
npm install
npm run dev        # Remotion Studio preview
npm run render     # -> out/PremiumReel.mp4
```

Rendered videos (`out/`, `*.mp4`) are git-ignored, so keep them out of the repository.
